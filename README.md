# Modern White Wedding Invitation

An elegant, interactive wedding invitation web experience for Aisha & Rayan.

## Features

- **Interactive Opening Gate**: Envelope & gold wax seal animation with smooth unveiling.
- **Mechanical Flip Clock**: Split-flap countdown timer to the wedding day (12 December 2026).
- **Background Music**: Romantic waltz audio player with autoplay upon opening and manual controls.
- **Our Story**: Beautiful photography and typography recounting the couple's journey.
- **Bride & Groom**: Portrait cards and biographies for Aisha & Rayan.
- **Order of Events**: Interactive timeline carousel showcasing every stage of the celebration.
- **Venue & Details**: Schedule, dress code guidelines, and embedded Google Maps for Villa Serena in Lisbon.
- **RSVP Experience**: Responsive form with attendance selection, guest count, and note submission.
- **Ultra-Responsive**: Engineered with clamp-based sizing and fluid layouts for phones, tablets, and laptops.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment to Vercel

```bash
# Deploy to Vercel directly
npx vercel

# Deploy to production
npx vercel --prod
```
